# Student Management System

A menu-based Student Management System built with Python and SQLite.

## Features

- Add student records
- View all student records
- Search students by name
- Update student information
- Delete student records
- Handle duplicate student names using unique IDs
- Basic email validation
- Basic phone number validation

## Technologies

- Python
- SQLite
- SQL

## Database

The application automatically creates a SQLite database named `studentdata.db` when the program runs.

## How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
python student_management.py
